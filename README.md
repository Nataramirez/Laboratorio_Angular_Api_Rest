# App

Aplicación Angular que consume datos de [JSONPlaceholder](https://jsonplaceholder.typicode.com/) y los
   muestra en tablas.

  ## ¿Qué hace?

  - Lista usuarios con nombre, username, email, teléfono y empresa
  - Lista posts con ID, título y descripción
  - Maneja estados de carga y error

  ## Tecnologías

  - Angular 21 (standalone components, signals)
  - JSONPlaceholder API
  - TypeScript

  ## Ejecutar

  ```bash
  npm install
  ng serve

  Abre http://localhost:4200
